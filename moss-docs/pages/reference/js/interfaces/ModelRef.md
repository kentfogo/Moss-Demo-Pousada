# ModelRef (JavaScript SDK)

> JavaScript reference to an embedding model, with its model identifier and version.

[@moss-js/moss](https://docs.moss.dev/docs/reference/js/api.md) / ModelRef

Reference to a model with version information.

## Properties

| Property | Type | Description |
| - | - | - |
| `id` | `string` \| `null` | Model identifier. |
| `version` | `string` \| `null` | Model version (semver/commit). |
