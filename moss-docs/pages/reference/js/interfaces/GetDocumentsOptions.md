# GetDocumentsOptions (JavaScript SDK)

> JavaScript options for fetching selected document IDs or all documents from a Moss index.

[@moss-js/moss](https://docs.moss.dev/docs/reference/js/api.md) / GetDocumentsOptions

Options for retrieving documents from an index.

## Properties

| Property | Type | Description |
| - | - | - |
| `docIds?` | `string`\[] | Optional array of document IDs to retrieve. If omitted, returns all documents. |
